# 简历项目描述（真实实验结果）

## 推荐版本

**LoRA-CLIP 文本行人检索与多模态分析系统**

- 基于 PEFT 对 CLIP ViT-B/32 进行 LoRA 领域适配，在注意力投影层注入低秩参数，实现自然语言描述与行人图像的跨模态特征对齐；仅训练 196.6 万个参数（占模型 1.283%，Adapter 约 7.89 MB）。
- 基于 RSTPReid 构建身份隔离的训练、验证、测试划分，设计 2,000 条文本查询对 1,000 张行人图库的统一评测流程；LoRA 微调后测试集 Recall@1/5/10 由 8.90%/21.25%/31.05% 提升至 34.70%/60.60%/72.05%，mAP 由 6.29% 提升至 27.90%。
- 完成 LoRA Rank、Alpha、目标模块及训练数据规模消融，结合参数量、峰值显存、吞吐与推理延迟分析性能—效率权衡；q/v-only 配置以 98.3 万参数取得 27.05% 验证 Recall@1，并输出相似度分布、UMAP 特征空间与典型失败案例。

## 一行精简版

基于 PEFT LoRA 适配 CLIP ViT-B/32 完成文本行人检索，在身份隔离的 RSTPReid 测试集上将 Recall@1 从 8.90% 提升至 34.70%、mAP 从 6.29% 提升至 27.90%，仅训练 1.283% 模型参数，并完成 Rank/Alpha/目标层/数据规模消融与检索可视化。

## 面试口径

- 主实验的 34.70% 是独立测试集结果；消融表中的数值来自验证集，不能直接混为同一组结果。
- 检索正样本按身份定义：文本所描述身份在图库中的任意同 ID 图像均算正样本。
- 主配置优先追求最终精度；q/v-only 是三轮消融中参数效率更高的轻量方案。
- UMAP 显示 LoRA 后仍存在一定模态间隔，因此应表述为“改善跨模态检索对齐”，不要宣称特征空间已完全重合。
